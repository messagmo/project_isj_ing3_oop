## Fonctionnalités implémentées
- Modélisation de 6 types d'équipements (Routeur, Switch, Serveur, Firewall, Wi-Fi AP, Terminal)
- Topologie avec liens (bande passante + latence)
- Routage BFS (Breadth-First Search)
- Simulation de trafic paquet par paquet
- Firewall avec authentification et journal horodaté
- Moniteur réseau et rapport exporté
- Menu interactif complet
